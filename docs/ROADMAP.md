# Roadmap

This is a list of directions to evaluate, not a delivery schedule. Priorities should follow real user problems and contributor capacity.

## Improve trust and usability

- Correct stale sources and clarify ambiguous claims.
- Gather keyboard, screen-reader, mobile, and print feedback.
- Expand meaningful calculator boundary and backup-compatibility checks.
- Explain difficult terms where readers encounter them.

## Make regional examples more useful

- Add reviewed country or regional notes with official sources and explicit dates.
- Separate local rules and currency examples from general decision principles.
- Improve regional examples only when contributors can maintain their evidence.

## Make contribution easier

- Add focused walkthroughs for editing a chapter and updating a source.
- Document the assumptions behind each calculator alongside its tests.
- Improve translation support after agreeing how updates and evidence will stay aligned.

## Ideas requiring validation first

- Additional scenarios for irregular income or shared household costs.
- Better accessibility of exported and printed notes.
- A small set of anonymized examples showing how evidence changed a decision.

Before proposing a feature, explain the decision it helps someone make and why the current guide cannot handle it. Preserve the ability to read and use the core toolkit without an account or backend. Avoid predictive salary scores, asset-picking signals, and features that imply more certainty than the evidence supports.
